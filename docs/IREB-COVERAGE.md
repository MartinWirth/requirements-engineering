# IREB coverage roadmap

This document maps the implementation roadmap to the IREB CPRE subject areas.

## Foundation

- Requirements Engineering principles
- Stakeholders and sources
- Requirements types and attributes
- Natural-language requirements
- Templates
- Models
- Validation
- Negotiation and conflict resolution
- Requirements management

## Use-case engineering

The use-case implementation is intended to support the elements described in IREB's Requirements Modeling material:

1. System boundary
2. Actors
3. Use cases
4. Associations
5. Use-case goals
6. Trigger
7. Preconditions
8. Postconditions
9. Main success scenario
10. Alternative scenarios
11. Exception scenarios
12. Include relationships
13. Extend relationships
14. Generalization
15. Detailed use-case specifications
16. Use-case diagrams
17. Traceability to requirements and acceptance criteria

## Modeling roadmap

- Context models
- Information structures
- UML class models
- Data-flow diagrams
- Activity diagrams
- State machines
- Sequence diagrams
- Communication diagrams

## Management roadmap

- Requirement lifecycle
- Prioritization
- Versioning
- Change management
- Dependencies
- Conflicts
- Traceability
- Baselines
- Reviews
- Impact analysis

## Important distinction

IREB defines a broad Requirements Engineering body of knowledge rather than a fixed list of software features. This repository therefore uses IREB's current syllabi and handbooks as the coverage baseline instead of claiming that one feature list is an official IREB specification.
